# 🧑‍🚒 Resgate Felino: O Bombeiro e o Gatinho 🐱

Um jogo interativo desenvolvido inteiramente com **HTML5 e CSS3** (sem JavaScript, utilizando _radio buttons_ e seletores CSS para controle de estado e navegação entre as telas).

No jogo, você assume o papel de um bombeiro em uma missão de resgate para salvar um gatinho preso em uma casa em chamas, enfrentando desafios e correndo contra o tempo!

🎮 **[Clique aqui para jogar](https://devpedro17.github.io/Casa-em-Chamas---Jogo-HTML/)**

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e inputs para controle do fluxo do jogo.
- **CSS3:** Estilização visual, layout responsivo com Flexbox, cores vibrantes e lógica de transição de telas via seletores CSS.

## 📌 Funcionalidades

- Lógica de estados e telas feita exclusivamente em CSS (`:checked ~ .screen`).
- Tema divertido e narrativo de resgate de um gato por um bombeiro.
- Telas dinâmicas de progresso, vitória e tentativa novamente.
